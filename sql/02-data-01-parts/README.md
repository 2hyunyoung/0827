# 02-data-01 분할 실행본

원본 02-data-01 파일이 SQL Editor 입력 한도를 초과할 때 사용하는 분할본입니다.

- part-01.sql부터 part-09.sql까지 순서로 실행하세요.
- 각 파일은 INSERT 문 중간에서 잘리지 않았습니다.
- 각 INSERT는 SQL Editor 호환성을 위해 최대 100행 단위로 나뉘어 있습니다.
- 원본 데이터는 수정하지 않았습니다.
- 이미 일부 파트를 실행했거나 중간에 실패했다면 실패한 파트부터 다시 실행하세요.
- 모든 INSERT 마지막 줄에 `ON CONFLICT DO NOTHING`이 적용되어 이미 들어간 행은 건너뛰고 누락된 행만 적재합니다.
